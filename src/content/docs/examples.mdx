Every example comes from the CLDK SDK test suite. Each snippet shows behavior that the tests cover. The examples are grouped by task. They use the same sample projects as the rest of these docs: a generic `my_pkg` for Python, and [Apache Commons CLI](https://commons.apache.org/proper/commons-cli/) for Java.

<Aside type="tip" title="One API, two languages">
The Python and Java pages follow the same pattern. First, the factory for the language builds the analysis (`CLDK.java(project_path=...)`, `CLDK.python(project_path=...)`). Then the analysis method for the task returns the result.
</Aside>
