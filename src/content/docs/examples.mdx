Every example calls the public methods of the CLDK Python SDK. The examples are grouped by task. They use the same sample projects as the rest of these docs. Python uses [Flask](https://github.com/pallets/flask), Java uses [Apache Commons CLI](https://commons.apache.org/proper/commons-cli/), and TypeScript uses [Zod](https://github.com/colinhacks/zod). JavaScript uses a small `my_app` project.

<Aside type="tip" title="One API, three languages">
The Python, Java, and TypeScript pages follow the same pattern. First, the factory for the language builds the analysis (`CLDK.java(project_path=...)`, `CLDK.python(project_path=...)`, `CLDK.typescript(project_path=...)`). Then the analysis method for the task returns the result. JavaScript projects use the TypeScript factory. Infrastructure-as-code has no factory yet. See the [codeanalyzer-iac](/backends/codeanalyzer-iac/) backend page.
</Aside>
