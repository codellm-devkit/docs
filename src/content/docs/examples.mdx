Every example calls the public methods of the CLDK Python SDK. The sample output is illustrative. The examples are grouped by task. They use the same sample projects as the rest of these docs: a generic `my_pkg` for Python, [Apache Commons CLI](https://commons.apache.org/proper/commons-cli/) for Java, a generic `my_app` for TypeScript and JavaScript, and the [Quarkus Coffee Shop](https://github.com/quarkuscoffeeshop/quarkuscoffeeshop-helm) Helm chart for infrastructure-as-code.

<Aside type="tip" title="One API, three languages">
The Python, Java, and TypeScript pages follow the same pattern. First, the factory for the language builds the analysis (`CLDK.java(project_path=...)`, `CLDK.python(project_path=...)`, `CLDK.typescript(project_path=...)`). Then the analysis method for the task returns the result. JavaScript projects use the TypeScript factory. Infrastructure-as-code has no factory yet, so its page uses the `caniac` command, `jq`, and Cypher.
</Aside>
