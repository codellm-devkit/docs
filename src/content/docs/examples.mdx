These examples are taken straight from the questions CLDK's own test suite asks of real projects, so every snippet reflects behavior the SDK actually guarantees, not a hand-wave. They're grouped by task and run against the recurring samples used across these docs: a generic `my_pkg` for Python and [Apache Commons CLI](https://commons.apache.org/proper/commons-cli/) for Java.

<Aside type="tip" title="Same facade, two languages">
Notice how little changes between the Python and Java pages: that's the point. You construct `CLDK(language=...).analysis(project_path=...)` and call the same methods regardless of language. Start with whichever you're analyzing.
</Aside>
